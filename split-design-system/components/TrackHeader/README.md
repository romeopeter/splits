The 180px column at the left of every timeline track.

**Provide:** `name`, `locked`, `hidden`, `onToggleLock`, `onToggleHidden`.

**Use:** the lock icon changes shape (closed or open shackle) and the eye icon is struck through when hidden, so state is never colour-only. Locked tracks dim their clips to `opacity-disabled` and refuse edits.

**Accessibility:** each header is a named group; buttons say what they will do ("Lock Track 2", "Show Track 3").
