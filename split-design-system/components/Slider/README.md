A continuous value: timeline zoom, volume, opacity.

**Provide:** `label` (required), `min`, `max`, `step`, `value` or `defaultValue`, `onChange`; `valueText` when the number needs a unit ("80 percent").

**Use:** the filled part is `accent`, the track is `border-control` (3:1), the thumb is white with an `accent` ring. Pair it with a visible value or minus and plus buttons.

**Accessibility:** native `input[type=range]`: Arrow keys step, Page Up and Down jump, Home and End reach the ends.
