Sets a colour and its opacity: text colour, shadow colour, fill.

**Provide:** `label` (used to name the swatch, hex and opacity inputs), `value` (a hex string), `opacity` (0–100).

**Use:** the swatch button opens the picker; the hex input accepts six digits without the hash; opacity is a percentage field. Show the value, never only the swatch.

**Don't:** rely on the swatch to communicate a colour; allow text colours below 4.5:1 without a warning in the inspector.
