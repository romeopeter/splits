The Spits icon set: 24px grid, 1.5px stroke, round caps and joins, no fills except transport and grip glyphs.

**Provide:** `name` from the Icons group, `size` (default 20; 16 in clips and dense rows, 24 in the rail), `title` only when the icon stands alone and carries meaning.

**Use:** icons inherit `currentColor`; set the colour on the parent from `text-secondary`, `text-primary` or `text-link`. Pair status icons (check, warning, alert, info) with a word. The SVG files in Icons carry a fixed neutral ink for preview; recolour them before export.

**Don't:** mix in another icon family, scale strokes with size, or use an icon without an accessible name from its button.
