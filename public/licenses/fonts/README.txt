Fonts bundled for text clips in Split (src/lib/fonts.ts).

They come from Fontsource npm packages (Latin subset, woff2). Each font's
licence is in this folder, copied from its package, because the SIL Open
Font License and the Apache License require the licence to travel with the
font. Permanent Marker is Apache-2.0; the others are OFL-1.1.

Hanken Grotesk ships with the Split design system (split-design-system/fonts).
